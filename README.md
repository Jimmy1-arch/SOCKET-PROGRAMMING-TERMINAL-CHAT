# 💬 SOCKET-PROGRAMMING TERMINAL CHAT

A terminal-based chat application built using socket programming in C++, enabling real-time client-server communication over TCP/IP networks.

---

## 🚀 FEATURES

- 📡 Real-time messaging using TCP sockets  
- 💻 Client-server architecture  
- ⚡ Low-latency communication over local network  
- 🔄 Bidirectional message exchange  
- 🖥 Lightweight terminal-based interface  
- 🔌 Multiple client support (if implemented)

---

## 🧠 SYSTEM ARCHITECTURE

Client ↔ Server ↔ Client

- **Server** → Handles incoming client connections and message broadcasting  
- **Client** → Connects to server and sends/receives messages  
- **Socket Layer** → Enables TCP/IP communication  

---

## 🛠 TECH STACK

- C++  
- Socket Programming (TCP/IP)  
- Linux / Unix Environment
